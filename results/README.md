# Ergebnisse

Hier landen die Ergebnisse, die in Papern und Folien verwendet werden:

| Datei | Erzeugt durch |
|---|---|
| `summary.md`, `summary.csv` | `make summary`: Mittelwert ± Std je Konfiguration über alle Seeds |
| `figures/` | Abbildungen für Paper und Folien (aus `runs/<name>/saliency_*.png` usw. kopieren) |

Einzelne Läufe (`runs/`) werden nicht committet, nur die zusammengefassten Ergebnisse.
